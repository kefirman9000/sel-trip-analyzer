    How to use

    Quick start

    1. Drag your relay's event files (or a whole folder) onto the drop zone. Best: the .CEV event report plus the relay's .RDB settings file.
    2. Read the summary. Lines marked CHECK are things the program is unsure about.
    3. Edit the text if needed, then Copy all or Export to Word or PDF.

    Your files are read inside this browser tab and are never uploaded. Nothing is installed.

    Which files to use

    .CEVCompressed event report: the most complete (elements, currents, usually the settings)
    .RDBQuickSet settings database: adds the trip equation (TR) and line length (LL)
    .EVE .TXTText event report or a saved terminal capture
    .SUM .HDREvent summary / COMTRADE header written by the relay
    .HISEvent history list: one line per event, least detail
    .SERSequential events recorder: element on/off times

    To get a CEV, download the event from the relay with AcSELerator QuickSet and choose the compressed (CEV) format, or save the output of the CEV command from a terminal session.

    Event types

    AG BG CGSingle phase-to-ground fault
    AB BC CAPhase-to-phase fault
    ABG BCG CAGTwo phases to ground
    ABCThree-phase fault
    TRIPTripped, but no fault type found (transfer trip, manual/SCADA, external input)
    EREvent recorded by the ER trigger; no trip
    TRIGManually triggered event
    … TA trailing T (for example "AG T") means the relay tripped

    Common targets

    INST instantaneous · TIME time-delayed · COMM communications-assisted · ZONE1/2/3 distance zones · 50 instantaneous overcurrent · 51 time-overcurrent · 81 frequency · SOTF switch-onto-fault · A B C G N faulted phases / ground · RS recloser reset (ready) · CY recloser cycling · LO recloser locked out

    Organizing the summary

    ShowAll events, trips only, needs review, faults only, or no-trip events (the numbers are how many events each includes)
    RelayOnly one relay's events
    SortOldest first, newest first, by relay, or needs review first
    DetailSummary only (overview + one line per event), Standard (adds details and CHECKs), or Full (adds element timeline, settings and SER)
    Hide duplicatesSkip history rows already covered by a detailed report
    SearchOnly events whose details contain the text

    The summary says which view it shows. Export → Spreadsheet gives one row per event with the same filter and order, ready to sort and filter in Excel.

    Confidence and checks

    HighElement data and settings, and nothing looked wrong
    MediumSome data missing, or one item to check
    LowHistory row only, very little data, or several items to check

    CHECK lines say exactly what to confirm: missing data (such as no settings), disagreements (targets vs. event type vs. currents), or unusual results (reverse or beyond-line location, slow breaker, off-nominal frequency).

    Fault location

    Shown in the relay's line-length units. With settings loaded it's also shown as a percentage of the line. Negative means behind the relay; $$$$$ means the relay couldn't calculate it.
