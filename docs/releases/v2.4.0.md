**Send your files to any history, and jump straight to it.** On the Events page, under the file list:

- **History** list: pick one of your saved histories, or **＋ New history…** to start one (it asks for a name).
- **Send to history** puts the files you've loaded into the picked history. Each event still counts once, so sending twice is harmless.
- **View in History** opens that history on the History tab.
- **Send new files automatically** keeps sending everything you load to the picked history.
- The list follows the History tab: switch histories there and the Events page picks the same one.
- The drop area now says "Drop relay event files".
